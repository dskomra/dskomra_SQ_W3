# Side Quest Week 3

## Setup and Interaction Instructions

**Running the Sketch**

Right-click on index.html and open in broswer using Live Server.

**Goal of the Game**

Be the first player to get 3 hits on your opponent!

**To Start or Restart the Game**
Press 'enter'

**Controls for Player 1**

- Move: A/D
- Attack: F
- Block: G

**Controls for Player 2**

- Move: left and right arrow keys
- Attack: K
- Block: L
